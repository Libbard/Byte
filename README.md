# بايت | Byte

*   **CS352 — تحليل وتصميم الأنظمة (System Analysis & Design)**

### المستوى السادس

## كيف تعمل المنصة

بايت مبني بطريقة مختلفة عن المنصات التقليدية. المقررات تُرفع كـ PDF ثم تُمرر على بايبلاين آلي ينتج صفحات ويب تفاعلية — شرح، رسوم بيانية، وفيديوهات تعليمية مقترحة.

### البنية التقنية
- **الواجهة:** HTML5 + Vanilla JS + CSS3 مع أوضاع داكنة وثيمات مخصصة لكل مادة. SVG تفاعلي ثنائي اللغة للرسوم التوضيحية.
- **المعالجة:** Python. بايبلاين يمتد من استخراج المحتوى إلى توليد الاختبارات. كل مرحلة مؤتمتة.
- 
### المميزات
*   اختبارات تفاعلية — MCQ ومقالي — مع نتائج فورية.
*   مخطط مذاكرة ذكي يبني لك جدول حسب صعوبة المواد ووقتك.
*   دعم كامل للعربية والإنجليزية — تبديل فوري لا يحتاج إعادة تحميل.
*   تجاوب مع الجوال والتابلت والحاسوب.
*   رسوم SVG توضيحية لكل مفهوم رياضي أو تقني معقد.
